# Paperang Tool

喵喵机（Paperang）热敏打印机逆向工具：**不依赖官方 App，通过经典蓝牙 SPP 直接控制打印机**。

一个 GUI，两种机型，附带完整协议文档和逆向过程记录。

## 支持的机型

| 机型 | 传输 | 协议 | 状态 |
|---|---|---|---|
| 喵喵机 P2（第一代） | 经典蓝牙 SPP | `02 … 03` | 走纸、黑白打印、浓度已验证 |
| 喵喵机 P2 HD | 经典蓝牙 SPP | A5 | 走纸、黑白打印已验证；浓度 3 档；灰阶格式已确认 |

> 两台机器在 Windows 上都会出现两个同名蓝牙设备，这是正常的：
> 一个是 BLE，一个是经典蓝牙。**工具必须用经典蓝牙那条**，
> BLE 链路上打印会被固件拒绝（查询正常）。

## 功能

- **机型选择**：P2 / P2 HD，自动切换协议
- **走纸**：1 / 3 / 5 / 10 / 20 / 50 行，或自定义 N 行，累计计数
- **打印测试**：10 行 / 20 行黑带、自检页
- **打印图片**：自动适配 576 点宽（超出裁掉、不足补白）
  - P2：黑白抖动
  - P2 HD：黑白抖动 / 灰阶 8、12、16 级
- **打印后自动走纸**：行数可调（默认 10）
- **浓度**：淡（55）/ 中（75）/ 浓（95）三档，两种机型统一
- **设备信息**：
  - P2：型号、电量、状态
  - P2 HD：DPI、加热点数、浓度、温度、速度、设备信息 JSON

## 快速开始

```bash
pip install -r requirements.txt
```

1. 打印机开机
2. Windows 设置 → 蓝牙和其他设备 → 添加设备 → 蓝牙 → 选择 `Paperang_P2` / `Paperang_P2 HD`
3. 双击 `paperang_tool.pyw`（无控制台窗口）
4. 选择机型 → 选择 `蓝牙链接上的标准串行 (COMx)` → 连接

使用细节、走纸标定、排错见 [`docs/usage.md`](docs/usage.md)。

## 协议速查

### P2（第一代）

```
02 | cmd | remain | len(2 LE) | data | CRC32(4 LE) | 03
CRC32 种子 0x35769521，只算 data 段
```

位图：576 点、72 字节/行、1bpp、MSB 在前、1 = 黑。

### P2 HD

```
A5 01 | len(2 LE) | content | CRC32(4 LE) | 5A
content = [parent, child, type, len(2 LE), data]
CRC32 种子 0x35769521
```

打印：`5/25` 开始 → `5/27` 数据 → `5/26` 结束 → `5/22` 走纸。

灰阶：`precision = 4`、`width = 288`，每字节两个 4bit 像素。

完整命令表见 [`docs/`](docs/)。

## 已知限制

- **不支持退纸**：两台机器的走纸参数都是无符号 16 位，负值会被解释成前进。
- **P2 HD 浓度只有三档**：固件忽略 55/75/95 之外的数值。
- **P2 HD 灰阶**：数据格式已确认（4bpp、288 字节/行、精度 4），实际观感受纸张和打印头限制。
- **必须使用经典蓝牙**：BLE 链路上打印命令会被拒绝。
- 不同批次硬件可能使用不同协议，异常时先确认机型和固件版本。
