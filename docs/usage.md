# 使用说明

## 1. 环境准备

### Python

需要 Python 3.9 或更高版本（安装时勾选 "Add Python to PATH"）。

安装依赖：

```bash
pip install -r requirements.txt
```

`paperang_tool.pyw` 只需要 `pyserial`；`examples/` 下的脚本额外需要 `Pillow`。

### 配对打印机

1. 打印机开机
2. 打开 **设置 → 蓝牙和其他设备 → 添加设备 → 蓝牙**
3. 在列表里选择 `Paperang_P2` 或 `Paperang_P2 HD`
4. 如果弹出配对确认，点「连接」

配对成功后，在 **控制面板 → 设备和打印机 → 蓝牙设备 → 属性 → 服务**
（或「更多蓝牙选项 → COM 端口」）可以看到 `蓝牙链接上的标准串行 (COMx)`。

> **同名设备出现两个是正常的。**
> 喵喵机是双模设备，会同时广播 BLE 和经典蓝牙。工具需要的是**经典蓝牙**那条。
> 如果列表里只有一个，配对即可，Windows 会按设备支持的方式建立连接。

> **手机 App 会抢占连接。**
> 打印机同一时间只能连接一个主机。使用工具前请退出手机上的喵喵机 App，
> 或关闭手机蓝牙。

## 2. 运行

双击 `paperang_tool.pyw`。

或命令行：

```bash
pythonw paperang_tool.pyw
```

`.pyw` 后缀配合 `pythonw.exe` 启动，不会出现黑色控制台窗口。

```

连接     端口 [COMx — 蓝牙链接上的标准串行]  [刷新] [连接]
走纸     行数 [5]
         [走1行][走3行][走5行][走10行][走20行][走50行]  [按N走]
         本次累计走纸：0 行
打印测试 [打10行黑带][打20行黑带][自检页]  ☑ 打完走 [10] 行
打印浓度 （随机型切换）
设备信息 —  [查询]
日志
```

### 选择机型

- **P2（第一代）**：`02 … 03` 协议
- **P2 HD**：A5 协议

机型决定了走纸、打印、浓度、查询使用的命令，选错会没有反应。
连接状态下切换机型会自动断开。

### 走纸

| 按钮 | 作用 |
|---|---|
| 走 1/3/5/10/20/50 行 | 快捷走纸 |
| 按 N 走 | 按「行数」框里的值走纸 |
| 本次累计走纸 | 本次会话累计行数 |

**走纸单位需要自己标定**：

1. 「行数」填 `100`
2. 点「按 N 走」
3. 用尺子量纸实际移动的毫米数
4. `1 行 = 实测毫米 ÷ 100`

350 dpi 的机器理论值是 0.0847 mm/行，但不同机型的步进定义可能不同，
以实测为准。

### 打印测试

- **打 10/20 行黑带**：打印一条实心黑带
- **自检页**：发送打印机内置的自检命令
- **打完走 N 行**：打印结束后自动走纸，默认 10 行，用来把图案送出机壳

> 打印结束后不会自动出纸。P2 HD 实测需要再走约 10 行才能看到图案底边。

### 打印图片

「打印图片」区：

1. 点「选择图片」，支持 PNG / JPG / BMP / GIF / WebP
2. **P2 HD** 可选处理模式：
   - **黑白抖动**：Floyd–Steinberg 抖动后转 1bpp
   - **灰阶 12 级**：转 4bpp，每字节两个像素
3. 点「打印」

图片会按 **576 点宽**处理：

- 宽度超过 576：裁掉右侧超出的部分（不缩放）
- 宽度不足 576：右侧补白
- 高度超过 3000 行：截断

两台机器的打印头都是 576 点宽（72 字节/行）。P2 HD 为 300 dpi；
P2 只确认了 576 点宽度，dpi 未单独标定。

### 浓度

**P2**：0–100 滑条，松手下发，另有 55/75/95 快捷按钮。

**P2 HD**：三档单选

- 淡（55）
- 中（75）
- 浓（95）

P2 HD 固件只认这三个值，其它数值不会产生可见变化。

### 设备信息

点「查询」读取：

- **P2**：型号、电量、状态
- **P2 HD**：DPI、加热点数、浓度、温度、速度、设备信息 JSON

## 4. 常见问题

### 打不开串口，错误 1231

```
OSError(22, '无法访问网络位置...')
```

原因：经典蓝牙没有完成配对，或打印机被手机占用。

处理：

1. 关闭手机蓝牙 / 退出喵喵机 App
2. 在 Windows 设置里重新配对
3. 确认端口是 `蓝牙链接上的标准串行`

### 打不开串口，错误 5（拒绝访问）

端口被其它程序占用。检查是否同时开了两个工具实例，或其它串口软件。

### 扫不到设备 / 设备不在广播

- 打印机可能已自动关机，重新开机
- 部分模块断开连接后会停止广播，需要短按电源键唤醒
- USB 插着充电时，部分机型会关闭 BLE 广播

### 命令返回成功但打印机不动

- 确认机型选择正确（P2 与 P2 HD 协议不同）
- 确认走的是经典蓝牙，不是 BLE
- 尝试重新配对，确保链路加密

### 打印出来是空白

- 热敏纸装反了（只有一面有涂层）
- 纸仓盖没有关紧
- 浓度过低或打印头脏污

### 打印内容错位 / 断裂

- 数据格式与机型不匹配
- 走纸打滑：降低浓度、减少实心黑面积
- 电量不足

### 走纸停不下来

走纸命令是固定行数，正常几秒内停止。如果持续运转：

1. 长按电源键关机
2. 检查是否误发了很大的行数（如 65535）

## 5. 安全建议

- 先用「走 1 行」确认链路，再逐步增加
- 实心黑会显著增加电流，长时间打印大块黑色可能造成走纸打滑
- 不要发送未知命令，部分命令会修改设备参数
- 打印机发热时暂停使用
