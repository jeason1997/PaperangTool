# 喵喵机 P2（第一代）协议

本文档描述第一代喵喵机 P2 通过**经典蓝牙 SPP** 通信时使用的 `02 … 03` 协议。

> 验证环境：Windows 11、Python 3.14、pyserial、喵喵机 P2（固件 1.x）。
> 该协议同样被 `paperang-p2-lib`、`python-paperang` 等开源项目采用，本文档中的命令表与之一致。

## 1. 传输层

- 经典蓝牙 SPP（RFCOMM），服务 UUID `00001101-0000-1000-8000-00805F9B34FB`
- Windows 配对后表现为 `蓝牙链接上的标准串行 (COMx)`
- 波特率对蓝牙串口无实际意义，按 `115200` 打开即可

## 2. 帧格式

```
偏移  长度  字段
0     1     0x02        帧头
1     1     cmd         命令字
2     1     remain      本包之后还剩几个包（最后一包为 0）
3     2     len         数据长度，小端
5     N     data        数据
5+N   4     CRC32       只对 data 计算，小端
9+N   1     0x03        帧尾
```

CRC32 参数：

- 多项式：标准 CRC-32（反射，`0xEDB88320`）
- **初始值：`0x35769521`**（不是标准的 `0x00000000`）
- 结果不做最终异或

等价实现：

```python
crc = zlib.crc32(data, 0x35769521) & 0xFFFFFFFF
```

示例帧（查询型号，data = `01`）：

```
02 06 00 01 00 01 D0 B9 59 E9 03
```

## 3. 命令表

`cmd` 为请求命令，设备返回 `cmd + 1`。

| cmd  | 方向 | 含义 | 数据 |
|------|------|------|------|
| 0x00 | → | 打印位图 | 行数据 |
| 0x01 | → | 打印压缩位图 | 压缩数据 |
| 0x04 | → | 查询固件版本 | `01` |
| 0x06 | → | 查询型号 | `01` |
| 0x08 | → | 查询蓝牙 MAC | `01` |
| 0x0A | → | 查询 SN | `01` |
| 0x0C | → | 查询状态 | `01` |
| 0x0E | → | 查询电压 | `01` |
| 0x10 | → | 查询电量 | `01` |
| 0x12 | → | 查询温度 | `01` |
| 0x15 | → | 查询工厂状态 | `01` |
| 0x18 | → | 设置 CRC key | 4 字节 |
| 0x19 | → | 设置浓度 | u16，0–100 |
| 0x1A | → | 走纸 | u16，行数 |
| 0x1B | → | 打印测试页 | 无 |
| 0x1C | → | 查询浓度 | `01` |
| 0x1E | → | 设置自动关机时间 | u16，秒 |
| 0x1F | → | 查询自动关机时间 | `01` |
| 0x21 | → | 走纸到打印头位置 | u16，行数 |
| 0x23 | → | 查询板版本 | `01` |
| 0x25 | → | 查询硬件信息 | `01` |
| 0x27 | → | 设置最大间隙 | u16 |
| 0x28 | → | 查询最大间隙 | `01` |
| 0x2A | → | 查询纸张类型 | `01` |
| 0x2C | → | 设置纸张类型 | 1 字节（0=普通） |
| 0x2D | → | 查询国家名 | `01` |
| 0x2F | → | 断开蓝牙 | 无 |

响应帧结构相同，`cmd` 为请求命令 + 1。

查询型号的响应示例：

```
02 07 00 0B 00 50 61 70 65 72 61 6E 67 5F 50 32 <CRC> 03
                 P  a  p  e  r  a  n  g  _  P  2
```

## 4. 位图格式

- 打印头：**576 点**（72 字节/行）
- 1bpp，**MSB 在前**：每字节最左边的点在 bit7
- **1 = 黑，0 = 白**
- 数据按行优先（row-major）排列

打包示例：

```python
def pack_row(pixels):           # pixels: 576 个 0/1
    out = bytearray()
    for x in range(0, 576, 8):
        b = 0
        for i in range(8):
            if pixels[x + i]:
                b |= 1 << (7 - i)
        out.append(b)
    return bytes(out)
```

## 5. 多包传输

单帧数据段建议不超过 **1014 字节**（14 行 × 72 字节 = 1008）。

- 把整幅图切成若干包
- 每包的 `remain` = 本包之后剩余的包数
- 最后一包 `remain = 0`

示例：96 行图像 = 6912 字节 = 7 包（前 6 包 14 行，最后一包 12 行）。

```
包1 remain=6, 包2 remain=5, ... 包7 remain=0
```

## 6. 典型打印流程

```
设置纸张类型 0x2C = 0
设置浓度   0x19 = 75
走纸       0x1A = 30
位图       0x00  × N 包
走纸       0x1A = 120
```

## 7. 注意事项

- **不支持退纸**。`0x1A` 的参数是无符号 16 位，负数补码会被解释成前进
  （`0xFFFF` = 65535 行）。
- 浓度只影响受热能量，对实心黑的影响有限；过高会加重走纸打滑。
- 不同批次固件可能在命令支持上有差异，遇到无响应先确认机型。
